# faf-dualgap-ai

[English](README.md) · **Русский**

Мод ИИ для **Supreme Commander: Forged Alliance Forever (FAF)** под карту **Dual Gap Adaptive v14** (6 на 6).
Каждый бот определяет роль по своему спавну и играет её: **GROUND** (мид по земле), **NAVAL** (вода), **AIR** (авиация) или **ECO** (экономика и гейм-эндеры).

Боты играют как команда, а не как двенадцать незнакомцев:
- **Командная игра.** Адаптивные роли (работа выбывшего игрока переходит к союзнику, который забрал его мексы), вызовы помощи,
  ПВО баз строит AIR, общая ПРО на трёх игроков.
- **Гейм-эндеры.** Планы как у игрока: обычно сначала одна ядерка, потом арта или T4; вся команда наваливается на замеченный вражеский гейм-эндер.
- **Авиация.** Массированные удары бомберов под прикрытием истребителей (сначала командир, потом гейм-эндеры, ПРО, T3-экономика),
  налёты Царя / Ахвассы с эскортом по краю карты на командира вражеского ECO, все свободные истребители на вражеский воздушный T4.
- **Наземка и флот.** Волны продавливают мид, а не стоят; флот перегруппировывается, а не скармливает корабли по одному;
  эсминцы помогают граунду на миде.
- **Командиры.** Прячутся в воде у своей базы, расходятся при пуске ядерки, уходят из плотной базы, если ПРО не заряжена,
  и прячутся под ПВО, когда летит вражеский воздушный T4.
- **База и экономика.** База как у игрока, с плотным примыканием; мексы базы T2 → хранилища → T3; траты растут вместе с доходом.

Обычный ИИ играет с туманом войны: он реагирует только на то, что его команда видела или видит на радаре.
Что изменилось в версии 2: [CHANGELOG.md](CHANGELOG.md) (на английском).

## Установка
1. Мод можно поставить двумя способами:
   - из **хранилища модов FAF**: найти **DualGap AI** (версия 2) в клиенте FAF и установить;
   - вручную: скопировать папку [`mods/DualGapAI`](mods/DualGapAI) в
     `%USERPROFILE%\Documents\My Games\Gas Powered Games\Supreme Commander Forged Alliance\mods\`.
     Папка должна называться именно `DualGapAI`.
2. В лобби FAF открыть **Mods**, включить **DualGap AI** и поставить ботов **AI: DualGap (beta)** или **AIx: DualGap (beta)** на карте Dual Gap Adaptive v14.
   Боты появляются в списке ИИ, только пока мод включён.

Подробно про роли, билд-ордер и настройки — в [mods/DualGapAI/README.md](mods/DualGapAI/README.ru.md).
Билд-ордеры и таблицы производства правятся в [DualGapBuildOrders.lua](mods/DualGapAI/lua/AI/DualGapBuildOrders.lua),
координаты и пороги — в [DualGapConfig.lua](mods/DualGapAI/lua/AI/DualGapConfig.lua).

## Разбор матчей (телеметрия)
С включённым модом каждая игра пишет телеметрию в лог FAF
(`%APPDATA%\Forged Alliance Forever\logs\game_*.log`) **для всех армий, включая живых игроков**:
раз в минуту снимок экономики и армии, раз в 3 минуты все постройки с координатами,
каждые 10 секунд готовые постройки (билд-ордер и раскладка базы) и положение юнитов (движение).
Просмотр реплея такой игры пишет ту же телеметрию заново.
Игра с sim-модом в FAF идёт без рейтинга.

Проще всего дважды кликнуть `analyze.cmd` в папке проекта: он напечатает отчёт по последнему матчу и откроет его карту.
Скрипты нужно запускать из папки проекта (`analyze.cmd` делает это сам).

```bash
python tools/parse_match.py
```
Последний матч короткой таблицей: строка на армию, автоматические флаги проблем (поздние техи, переполнение массы,
нехватка энергии, простаивающие инженеры, застрявшие проекты, генераторы не у заводов, мало хранилищ у мексов...)
и билд-ордеры живых игроков. Полный отчёт пишется в `reports/<лог>.json`.

```bash
python tools/draw_match.py
```
Интерактивная карта (`reports/<лог>.html`) с ползунком времени: постройки в настоящем размере, юниты и следы армий.

```bash
python tools/batch_report.py --last 10
```
Десять матчей одной таблицей: боты по ролям рядом с живыми игроками (тайминги техов, экономика, качество раскладки базы,
время первой ПВО, щита, T3...). Её удобно вставить в чат для разбора.

```bash
python tools/draw_base.py ARMY_6
```
База одной армии на 10, 21, 30, 42 и 60 минутах (`reports/<лог>_<армия>_base.html`) и что к чему примыкает,
чтобы сравнить базу бота с базой игрока.

## Тесты
Офлайн, без игры (нужен Python 3 и `pip install lupa`):

```bash
python tests/run_tests.py
```

Тесты проверяют синтаксис и совместимость с Lua 5.0, пути импорта и ссылки между модулями, роли и владение мексами на реальных маркерах карты,
решения командира, правила производства и прогоняют весь дебют на мини-симуляции.

`tools/map_markers.py` выводит маркеры карты из `*_save.lua`, он пригодится для калибровки координат.
